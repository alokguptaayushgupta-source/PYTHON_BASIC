# Python Problem Solving & Logic Building — 100 Question Starters

This repository contains **100 empty Python starter files** based on the question statements in the supplied *Python: 100 Questions with Solutions* guide. The original question order and statements are preserved. Solutions are intentionally left for you to write independently.

## How to use
1. Open a question file, read the problem statement at the top, and solve it yourself.
2. Write your code under `# YOUR SOLUTION STARTS HERE`.
3. Run the file and test more than one input, including edge cases where relevant.
4. When you understand your approach, add a short explanation and complexity notes if appropriate.
5. Commit work in meaningful batches, e.g. `Solve Q001-Q005: basic arithmetic`.

## Difficulty groups
- `01_Easy_Q001-Q020`: Questions 1–20
- `02_Easy_to_Medium_Q021-Q040`: Questions 21–40
- `03_Medium_Q041-Q060`: Questions 41–60
- `04_Medium_to_Hard_Q061-Q080`: Questions 61–80
- `05_Hard_Challenges_Q081-Q100`: Questions 81–100

## Suggested workflow per problem
- Understand what the problem asks.
- Work through a small example by hand.
- Write the logic before coding.
- Test normal and boundary cases.
- Explain why your solution works in your own words.

**Note:** The questions are grouped by the difficulty map in the source guide, not strictly by programming topic. Filenames use global question numbers (`Q001`–`Q100`) so they remain unique and easy to search.
